Security Policy

We follow responsible disclosure and coordinated vulnerability handling. Please report security issues privately.

Reporting a Vulnerability
Send a detailed report to security@psms.ai including:
- Description of the issue
- Steps to reproduce
- Affected components and impact
- Suggested mitigation or patch if available

Response Expectations
We will acknowledge receipt within 72 hours and provide a point of contact. We will coordinate disclosure and remediation timelines based on severity and safety impact.

Scope
This policy covers software in this repository and services deployed as part of PSMS.

Emergency
If a vulnerability poses an immediate safety risk, follow local emergency procedures and notify appropriate authorities in addition to contacting the maintainers.

Responsible Disclosure
Please avoid public disclosure until a fix is available. Do not perform actions that would leak private data or disrupt availability beyond what is necessary to demonstrate the issue.
